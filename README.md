# 🦸 祖国人桌面宠物 (Homelander Desktop Pet)

一个基于纯HTML/CSS/JS的桌面宠物，以《黑袍纠察队》中的祖国人(Homelander)为原型。

## ✨ 功能特性

### 🖱️ 拖动飞行
- 拖拽祖国人即可让他飞行
- 飞行时披风会飘动，身体会倾斜
- 松手后带有惯性滑动效果
- 飞行轨迹粒子特效 + 速度线

### 💬 点击语录
- 单击祖国人触发随机语录
- 包含多条经典祖国人台词（中英文）
- 语录以气泡形式显示在头顶

### 👁️ 双击镭射眼
- 双击触发镭射眼特效
- 眼睛发红光，射出激光束
- 屏幕震动 + 爆炸效果
- 持续2秒后恢复正常

### 🎨 其他细节
- 闲置时悬浮动画
- 眼睛跟随鼠标移动
- 纯CSS绘制角色（金发、蓝色战服、红色披风、金色徽章）
- 适配移动端触摸操作

## 🚀 使用方法

直接用浏览器打开 `index.html` 即可！

```bash
# 或者用任何本地服务器
npx serve .
```

```
Desk_pet/

```

## 🎮 操作说明

| 操作 | 效果 |
|------|------|
| 拖拽 | 祖国人飞行 + 动态特效 |
| 单击 | 显示随机语录 |
| 双击 | 触发镭射眼攻击 |
